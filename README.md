# CodexDiaRepair — Codex 对话数据修复与备份工具

CodexDiaRepair 是 Codex 桌面端（ChatGPT 桌面应用里的 Codex）的本地对话修复、备份与恢复工具。解决的核心问题是：**对话数据存放在本地，但 Codex 侧栏看不到，或数据不一致、需要备份/恢复的情况**。

本工具只读写你的 Codex 本地数据目录（默认 `C:\Users\<用户名>\.codex`），不改动你的模型与认证配置（除非你在诊断结果里主动确认修复认证冲突）。

---

## 适用情况

适合在以下场景使用：

- 切换模型供应商 / 路由（如用 cc-switch 或 DeepSeek 脚本切换后），Codex 侧栏看不到历史对话。
- 本地对话存在，但 Codex 列表显示不全、打不开或顺序混乱。
- 需要给 Codex 本地对话做完整备份，或从备份恢复到某个时间点。
- 误删对话后需要从废纸篓恢复。
- 需要导入 / 导出对话，或在多台机器之间迁移。
- 需要诊断"本地数据损坏"与"登录/云同步失效"是哪种问题。

不适合 / 边界：

- 侧栏同一时刻只显示当前 provider 的会话；"修复对话可见度"会把历史会话的 provider 对齐到当前 provider。
- 云同步（在网页/手机端看到对话）与侧栏可见性是两回事：API 登录下应用不会把对话上传到云端，本工具不负责也不强制改变你的登录方式。
- `\\?\` 这样的路径前缀是 Codex 在 Windows 上的正常写法，不是问题，工具不会把它当故障清理。

---

## 使用方法

1. 修复、恢复类操作前：**完全退出 Codex**。
2. 双击 `CodexDiaRepair.exe` 启动。
3. 顶部选择 Codex 数据目录，默认 `C:\Users\<用户名>\.codex`，一般不用改。
4. 在底部页签中操作：**对话管理 / 废纸篓 / 备份与恢复 / 诊断与修复**。

任何修改类操作前，程序都会自动备份；备份默认保存在 `%LOCALAPPDATA%\DiaRepair\备份`，可在"备份与恢复"页修改位置。

## 功能总览（按页签）

### 对话管理

显示 Codex 本地所有对话（分"聊天窗口"和"归档对话"两个列表），支持按项目目录和 Provider 过滤。

| 控件 / 按键 | 功能 |
| --- | --- |
| 项目下拉框 + Provider 下拉框 | 按项目或 provider 过滤对话列表 |
| 筛选 / 清除 | 应用 / 清除过滤条件 |
| 全选 / 取消 | 勾选或取消勾选全部对话 |
| 移入废纸篓 | 把选中对话移入废纸篓（可恢复） |
| 彻底删除 | 永久删除选中对话（不可恢复，慎用） |
| 导出选中 | 导出选中对话为文件 |
| 导入 | 从导出文件导入对话 |
| **修复对话可见度** | 一键诊断并修复"Codex 看不到对话"的问题（切换 provider 后使用，需确认，需先关闭 Codex） |

列表行点击可勾选/取消；顶部的灰色提示说明了修复对话可见度的用途和前提。

### 废纸篓

| 按键 | 功能 |
| --- | --- |
| 刷新 | 刷新废纸篓列表 |
| 恢复选中 | 把选中的废纸篓对话恢复到原位置（含会话文件、数据库记录、索引） |
| 清空废纸篓 | 永久清空废纸篓（不可恢复） |

### 备份与恢复

备份分为两种：

- **完整备份**（立即备份产生）：包含数据库、索引、配置和全部会话文件，可完整回到备份时间点。
- **核心数据备份**（修复流程自动产生）：只包含数据库、索引、配置，不含会话文件，用于撤销本次修复。

备份列表的"包含内容"列会标明是"含会话(N)"还是"仅核心数据"。

| 控件 / 按键 | 功能 |
| --- | --- |
| 备份根目录 + 选择 / 应用 | 设置备份保存位置（会记住，重启后仍生效） |
| 立即备份 | 创建完整备份（含全部会话文件） |
| 刷新 | 刷新备份列表 |
| 恢复选中 | 用选中备份覆盖当前数据；完整备份=回到该时间点，核心备份=仅回退数据库/索引/配置 |
| 验证 | 校验选中备份是否完整 |
| 删除备份 | 确认后删除选中备份（不可恢复） |
| 双击列表项 | 查看备份内容：完整备份显示对话列表，核心备份显示文件清单 |

### 诊断与修复

| 控件 / 按键 | 功能 |
| --- | --- |
| 刷新诊断 | 重新扫描并列出问题（本地数据问题、认证冲突等） |
| 执行修复 | 按诊断结果执行修复项（需确认；认证类修复默认需人工确认） |
| 问题列表 | 每条问题的级别、类型、描述和修复方向 |

修复对话可见度的弹窗里会列出发现的问题（如"N 个会话文件的 provider 与当前 provider 不一致"），可逐项勾选，高风险整库恢复默认不勾选。

## 注意事项

- **修复、恢复、删除前请先完全退出 Codex**：Codex 运行时会占用数据库并覆盖你的修改，程序会检测到运行中的 Codex 并拒绝执行。
- 所有修改类操作前自动完整备份，可在"备份与恢复"页查看和回滚。
- 删除备份、清空废纸篓、彻底删除对话均**不可恢复**。
- 整库恢复属于高风险操作：会回退该备份之后产生的所有变更，默认不勾选。
- 切换 provider 后侧栏看不到历史对话，请使用"对话管理 → 修复对话可见度"，它会将会话的 provider 对齐到当前 provider；前提是切换后的 provider 在配置里有定义。
- 云同步与侧栏可见性相互独立：API 登录下对话不会上传云端；如需云同步请使用 ChatGPT 账号登录。
- 本工具是绿色单文件程序；Windows 可能弹出 SmartScreen 提示，选择"仍要运行"即可。
- exe 是打包时刻的代码快照，发布新版本需要重新打包。

## 常见问题

- **为什么修复后 Codex 里还是看不到对话？** 请确认已完全退出 Codex 再执行修复，修复完成后重新启动 Codex；如仍未显示，先看"诊断与修复"里是否还有 provider 不一致问题。
- **为什么备份有时很小？** 修复流程自动备份只含核心数据（不含会话文件），完整备份才含会话文件，列表"包含内容"列有标明。
- **为什么校验未通过？** 旧版本曾把可再生的 `-shm` 临时文件纳入校验导致误报；新版本已修复，重新备份后应通过。
- **数据备份存在哪里？** 默认 `%LOCALAPPDATA%\DiaRepair\备份`，可在备份与恢复页修改。
